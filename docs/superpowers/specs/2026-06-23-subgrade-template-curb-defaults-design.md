# 路基模板路缘石与默认参数优化设计说明

日期：2026-06-23

## 目标

优化路基模板部件的默认颜色、默认坡度和路缘石参数表达，使创建、编辑、实体显示、DWG 持久化、道路模型生成和 Agent 工具使用同一套领域语义。

## 功能范围

- 路基模板部件新增内侧路缘石和外侧路缘石两组参数。
- 路基模板默认部件颜色按左右侧和部件类型生成。
- 默认模板中的初始部件删除路缘带。
- 行车道、硬路肩、路缘带和土路肩按左右侧生成默认坡度。
- 删除用户可编辑的部件高度差，高差改由路缘石高度参数驱动。
- WPF 参数窗口、Bridge 文件、ObjectARX 自定义实体、道路模型和测试同步支持新增字段。

## 部件路缘石参数

每个路基模板部件保存两组路缘石参数：

- 是否有内侧路缘石。
- 内侧路缘石宽度、高度、埋深。
- 是否有外侧路缘石。
- 外侧路缘石宽度、高度、埋深。

宽度、高度和埋深均为非负有限值。未启用对应路缘石时，该组宽度、高度和埋深在归一化时置零。

路缘石宽度不扣减部件总宽。部件普通断面的有效宽度仍为部件总宽；路缘石宽度按对应侧向当前部件内部重复绘制，作为构造表达，不改变该部件与相邻部件的累计宽度关系。

路缘石顶部与当前部件顶部一致并保持平行，不再绘制为高出当前部件顶面的构造。路缘石按部件颜色填充，并增加白色描边。埋深继续表示路缘石低于相邻较低部件起点的下埋尺寸。

路缘石高度参与部件高差：

- 内侧路缘石高度作用于当前部件，当前部件内侧起点相对上一内侧部件抬高同等高度。
- 外侧路缘石高度作用于外侧相邻部件，当前部件外侧之后的下一部件起点降低同等高度。
- 旧的部件高度差输入从 WPF 和 Agent 用户协议中移除；内部遗留字段仅用于旧文件兼容，归一化和新响应中置零。

## 默认颜色

默认颜色使用 AutoCAD ACI 色号的 RGB 近似值写入当前 RGB 字段，保持 WPF、实体和 Agent 之间的数据结构稳定。

| 部件类型 | 左侧 ACI | 右侧 ACI |
| --- | ---: | ---: |
| 中分带 | 42 | 52 |
| 行车道 | 32 | 62 |
| 侧分带 | 92 | 102 |
| 硬路肩 | 22 | 72 |
| 慢车道 | 22 | 72 |
| 土路肩 | 12 | 82 |
| 人行道 | 12 | 82 |
| 路缘带 | 43 | 61 |

道路偏置线仍保留色号 7 的规则语义，但本次默认模板初始部件不再包含路缘带，也不新增独立道路偏置线部件。

## 默认坡度

坡度符号按项目当前约定：

- 左下为正。
- 右上为负。
- 平坡为 `0`，顺时针旋转为负，逆时针旋转为正。

因此默认坡度为：

- 左侧行车道、硬路肩、路缘带：`0.02`。
- 右侧行车道、硬路肩、路缘带：`-0.02`。
- 左侧土路肩：`0.03`。
- 右侧土路肩：`-0.03`。
- 其他部件暂时为 `0`。

慢车道暂不自动套用 2% 坡度，除非后续业务把慢车道明确归入硬路肩或行车道类部件。

几何生成时不改变上述数值符号。左侧 `0.02` 的外侧高程应降低，右侧 `-0.02` 的外侧高程也应降低；也就是说默认值正确，应用到图形和道路模型时需要按旋转符号换算外向高程。

## 默认模板调整

所有道路等级的默认模板初始部件中删除路缘带。既有 `CurbStrip` 类型保留，供用户手动新增或旧图纸读取。

默认模板中所有中分带部件外侧路缘石默认启用，宽度、高度和埋深均为 `0.15`。手动新增中分带时也使用同一组默认外侧路缘石参数。

高速公路、一级道路、城市主干道、城市次干道和城市支路等已有路缘带初始项的默认列表，需要移除对应 `CurbStrip` 项；其他默认部件顺序保持不变。

## 架构边界

- `domain/cross_section` 保存路缘石字段、默认颜色、默认坡度、归一化规则和几何辅助计算，不依赖 ObjectARX 或 WPF。
- `cad_adapter/objectarx` 负责 DWG 版本升级、实体绘制和 Bridge 文件读写。
- `ui/wpf` 只负责参数输入、字段启用状态、二维预览和请求响应文件读写。
- `application/agent` 只做工具 JSON 到路基模板参数的转换，不写几何算法。

## 兼容性

- `DnSubgradeTemplateEntity` 持久化版本升级。读取旧版本 DWG 时，新增路缘石字段默认为未启用且尺寸为零。
- Bridge 文件新增字段应保持可选。旧请求文件缺字段时，WPF 按未启用路缘石处理。
- Agent 工具缺省参数不要求用户提供路缘石；默认创建结果仍按道路等级模板生成。
