# 路基模板路缘石与默认参数优化实施计划

日期：2026-06-23

## 约束

- 在主项目目录 `F:\0_GPT_道路设计原型功能项目` 直接开发，主目录保持最新文档和代码。
- 先补失败测试，再实现。
- `domain` 层不依赖 ObjectARX 或 WPF。
- WPF 只做界面、预览和 Bridge 文件读写。
- DWG 旧版本读取必须有默认兼容值。
- `docs/superpowers/plans/` 下计划文档必须使用中文。

## 步骤

1. TDD 红灯
   - 增加默认颜色按左右侧和部件类型生成的核心测试。
   - 增加默认坡度按左右侧生成的核心测试。
   - 增加默认模板不再包含路缘带的核心测试。
   - 增加路缘石参数归一化测试。
   - 增加托管 Bridge 读写内外侧路缘石字段的测试。
   - 增加左正右负坡度按旋转符号换算外向高程的道路模型测试。
   - 增加内侧路缘石高度影响当前部件、外侧路缘石高度影响外侧相邻部件的道路模型测试。
   - 增加 WPF 移除高度差输入、CAD 路缘石填充描边的源码契约测试。

2. Domain
   - 在 `SubgradeTemplateComponent` 中增加内外侧路缘石字段。
   - 增加按 `SubgradeSide + SubgradeComponentType` 获取默认颜色和默认坡度的规则。
   - 增加坡度外向高程换算、内侧路缘石高差和外侧路缘石高差辅助规则。
   - 默认模板创建时使用新的颜色和坡度规则，并删除默认路缘带。
   - 归一化校验路缘石参数，并将旧部件高度差字段置零。

3. ObjectARX
   - `DnSubgradeTemplateEntity` 持久化版本升级并读写新增字段。
   - 更新实体绘制逻辑，部件普通断面宽度保持不变，内外侧路缘石按部件内部重复宽度绘制。
   - 路缘石顶部与当前部件顶部一致，使用部件颜色填充并加描边。
   - 更新几何范围计算，覆盖路缘石高度和埋深。
   - 更新 WPF Bridge 文件读写新增字段。

4. WPF
   - DTO 和请求响应文件读写新增内外侧路缘石字段。
   - 参数窗口增加内侧/外侧路缘石开关和宽度、高度、埋深输入，并移除旧部件高度差输入。
   - 预览中绘制路缘石构造，保持普通断面宽度不被扣减，并按路缘石高度改变相邻部件高差。
   - 默认模板构造逻辑同步新的颜色、坡度和删除路缘带。

5. 文档同步
   - 更新路基模板创建、编辑和 WPF 桥接业务文档。
   - 更新横断面模块说明和路基模板复用说明。
   - 更新版本记录和测试说明中相关能力描述。

6. 验证
   - 运行核心测试。
   - 运行托管 Bridge 测试。
   - 如本机工具链可用，构建相关项目。
   - 检查 `git status --short`，确认只包含本次相关修改。
