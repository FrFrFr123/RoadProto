# 整幅路路面结构层模板_编辑

## 基本信息

- 功能名称：整幅路路面结构层模板编辑
- 所属模块：横断面设计
- 命令名称：`RD_SECTION_FULL_ROAD_PAVEMENT_TEMPLATE_EDIT_HANDLE`
- 对应代码入口：`src/cad_adapter/objectarx/cross_section/ObjectArxFullRoadPavementTemplateCommand.cpp`
- 业务文档维护人：RoadProto 项目
- 原型版本：`v0.1.36`
- 是否可复用：部分可复用

## 功能背景

整幅路路面结构层模板保存的是某个参考路基模板在某一时刻的快照，以及每个快照部件内嵌的结构层配置。编辑时应保留实体已保存的数据，不因参考路基模板后续变化而自动重建。用户需要刷新时，由窗口显式发起参考路基模板重新点选。

## 业务目标

- 双击 `DnFullRoadPavementTemplateEntity` 或按 handle 打开同一个 WPF 窗口。
- 显示上次保存的模板名称、显示比例、参考路基模板 handle/名称/道路等级、部件快照和每部件结构层。
- 支持在预览中点选路基部件和具体结构层，也支持左/右按钮切换当前路基部件。
- 保留原有上/下结构层切换、新增/删除层、材料推荐、颜色、填充、厚度、加宽和坡度一致复选框等交互；厚度、加宽、坡度的统一值与内外侧拆分行应与单部件路面结构层模板一致，输入 `1.5`、`.5`、`1:1.5` 等小数或坡度比例时不得被编辑过程中的预览刷新截断。
- 预览支持滚轮缩放、中键拖动、结构层颜色和填充显示，并用 `中线` 标记道路中心线。
- 用户刷新参考路基模板时，按 `侧别 + 类型 + 同侧同类型序号` 匹配并保留结构层；匹配不到的新增部件只在行车道和硬路肩上套默认预设。
- 编辑回写只更新整幅路模板实体，不修改参考路基模板。

## 输入条件

- CAD 选择对象：`DnFullRoadPavementTemplateEntity` handle。
- 用户输入参数：WPF 编辑后的模板信息、部件快照和结构层参数。
- 已有设计实体：待编辑的整幅路模板实体；刷新时可重新选择参考路基模板实体。
- 外部数据：无。

## 输出结果

- CAD 图形实体：更新原 `DnFullRoadPavementTemplateEntity`
- 领域实体：更新后的 `FullRoadPavementTemplateData`
- 表格或报告：无
- 更新通知或重建请求：无。

## 操作流程

1. 用户双击整幅路模板实体，或发送 `RD_SECTION_FULL_ROAD_PAVEMENT_TEMPLATE_EDIT_HANDLE <handle>`。
2. ObjectARX 解析 handle，校验对象类型为 `DnFullRoadPavementTemplateEntity`。
3. C++ Bridge 写入请求文件并打开 WPF 窗口。
4. WPF 按实体数据恢复部件顺序、当前部件、结构层列表和当前层。
5. 用户可直接编辑结构层，也可点击 `选择/刷新参考路基模板` 回到 CAD 重新点选路基模板。
6. 刷新参考模板时，C++ 读取新的路基模板部件快照，按 `侧别 + 类型 + 同侧同类型序号` 保留原结构层，并重新打开 WPF。
7. 用户确认后，WPF 写出响应文件。
8. C++ 读取响应并回写原实体。

## 关键业务规则

- 编辑既有实体时不得自动重新读取参考路基模板。
- 刷新参考路基模板只能由用户在窗口中显式触发。
- 刷新匹配 key 由三部分组成：部件侧别、部件类型、同侧同类型序号。
- 匹配成功的部件保留原结构层，只刷新宽度、坡度、颜色、变宽/变坡表和路缘石等路基参数。
- 匹配失败的新增部件按创建规则处理：行车道和硬路肩可套默认预设，其他部件保持空结构层。
- 被删除或匹配失败的旧部件不写入刷新后的快照。
- 编辑命令不修改参考路基模板实体，不生成道路模型，不绘制横断面图。
- WPF 预览应表达部件坡度和路缘石实体；中分带和侧分带顶线保持平整，路基部件本身只显示为彩色顶线，结构层按颜色、填充和四边形轮廓表达厚度、加宽和坡度。
- 整幅路预览中的路缘石必须沿用路基模板定义：路缘石宽度在当前部件内部重复绘制且不扣减部件总宽；路缘石顶部与当前部件顶部一致并保持平行；内侧路缘石高度抬高当前部件内侧起点，外侧路缘石高度降低外侧相邻部件起点；埋深继续向下表达。
- WPF 预览应显示部件名称、宽度和坡度；启用路缘石时显示宽度/高度/埋深的简化尺寸文字，便于核对从参考路基模板提取的快照参数。
- CAD 实体显示完整整幅路示意、所有参考路基部件、已配置结构层、中线标记、模板名称和参考路基模板名称；CAD 实体的部件坡度、路缘石高差和路缘石白色描边应与 WPF 预览使用同一套路基模板规则。
- CAD 实体中的结构层显示应参考单部件 `DnPavementLayerTemplateEntity` 的方法，调用 `PavementLayerTemplateRules::buildSection` 生成每个部件的结构层四边形，再按层颜色、显示方式和填充参数绘制填充、填充线和边线；不得只按平均厚度或简化矩形表达。

## 可复用性说明

- 可复用内容：按部件 key 保留结构层的刷新规则、整幅路模板 DWG 持久化、WPF 部件选择和结构层编辑 helper。
- 临时原型内容：双击事件由托管 Ribbon 插件转发 handle 命令。
- 正式复用前需要改造的内容：引用关系查询、刷新影响预览、批量替换和模板库版本管理。

## 与其他模块的依赖关系

- 上游模块：横断面路基模板。
- 下游模块：后续道路模型生成和横断面图配置可读取整幅路模板。
- 实体联动行为：当前版本没有自动联动。

## 后续对接正式 EICAD 功能的注意事项

- 后续应在参考模板变化时提供差异提示，但是否刷新仍应由用户确认。
- 后续横断面图配置可优先读取整幅路模板，再覆盖局部部件结构层。
