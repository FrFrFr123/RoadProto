# 整幅路路面结构层模板_创建

## 基本信息

- 功能名称：整幅路路面结构层模板创建
- 所属模块：横断面设计
- 命令名称：`RD_SECTION_FULL_ROAD_PAVEMENT_TEMPLATE_CREATE`
- 对应代码入口：`src/cad_adapter/objectarx/cross_section/ObjectArxFullRoadPavementTemplateCommand.cpp`
- 业务文档维护人：RoadProto 项目
- 原型版本：`v0.1.36`
- 是否可复用：部分可复用

## 功能背景

既有 `DnPavementLayerTemplateEntity` 只表达单个路基部件的路面结构层模板，并由路基模板部件通过 handle 引用。本功能新增独立的整幅路模板实体，用于从一个路基模板实体提取整条路的部件快照，并在同一个实体中内嵌每个部件的结构层参数。

整幅路模板不改变既有单部件模板的使用方式。本版本不接入道路模型生成、不接入横断面图生成、不参与工程量统计，只提供 DWG 自定义实体持久化和后续读取入口。

## 业务目标

- 在横断面 Ribbon 增加 `整幅路路面结构层模板` 入口。
- 创建独立 `DnFullRoadPavementTemplateEntity`。
- 创建流程先打开 WPF 参数窗口，再在确认后提示点取实体插入点。
- 支持用户在窗口中选择或刷新参考 `DnSubgradeTemplateEntity`。
- 从参考路基模板读取模板名称、道路等级和左右侧部件参数，保存为快照，不自动联动。
- 每个路基部件内嵌一组 `PavementLayerTemplateLayer` 语义的结构层数据，不引用单部件路面结构层模板 handle。
- 未选择参考路基模板时，预览区显示 `请选择路基模板提取参数`，结构层编辑区禁用，不能确认生成实体。
- 预览区沿用既有路面结构层模板的交互路径，支持滚轮缩放、中键拖动画布、点选路基部件和点选具体结构层。
- 只给行车道、硬路肩自动套用既有文档预设，其他部件默认没有结构层。
- CAD 实体显示所有路基部件和已配置结构层，简化显示，不画复杂尺寸标注。
- 本次不做 XML 导入导出。

## 输入条件

- CAD 选择对象：窗口中点选参考 `DnSubgradeTemplateEntity`。
- 用户输入参数：模板名称、显示比例、当前路基部件、每个部件的结构层列表、每层类型、名称、颜色、填充、厚度、内外侧加宽和坡度。
- 已有设计实体：可选参考路基模板实体。
- 外部数据：无。

## 输出结果

- CAD 图形实体：`DnFullRoadPavementTemplateEntity`
- 领域实体：`FullRoadPavementTemplateData`
- 表格或报告：无
- 更新通知或重建请求：无。参考路基模板只作为快照来源。

## 操作流程

1. 用户运行 `RD_SECTION_FULL_ROAD_PAVEMENT_TEMPLATE_CREATE`，或点击 Ribbon `横断面设计 / 整幅路路面结构层模板`。
2. C++ 创建空的 `FullRoadPavementTemplateData` 并打开 WPF 窗口。
3. 未选择参考路基模板时，预览区显示 `请选择路基模板提取参数`，结构层编辑区不可用，确认按钮不可用。
4. 用户点击 `选择/刷新参考路基模板`，WPF 写出点选动作响应并返回 CAD。
5. C++ 提示用户点选 `DnSubgradeTemplateEntity`，读取路基模板参数，生成整幅路部件快照并重新打开 WPF。
6. WPF 对行车道部件默认套用“主线行车道”预设，对硬路肩部件默认套用“主线硬路肩”预设，其他部件保持空结构层。
7. 用户逐个点选或切换路基部件，按既有路面结构层模板窗口相同交互维护结构层。
8. 用户确认后，C++ 提示点取插入点。
9. C++ 创建 `DnFullRoadPavementTemplateEntity`，写入插入点、参考路基模板信息、部件快照和每部件结构层数据。

## 关键业务规则

- 新功能独立于 `DnPavementLayerTemplateEntity`，不得修改既有单部件路面结构层模板的引用模式。
- 参考路基模板采用快照机制。创建实体后，参考路基模板变更不会自动同步到整幅路模板。
- 部件快照保存宽度、坡度、类型、颜色、变宽表、坡度变化表、内外侧路缘石宽度/高度/埋深等参数。
- 部件切换顺序按横断面图面几何顺序：最左外侧到中线，再到右侧外侧。
- 预览图中的每个路基部件都可点选，点选后切换当前路基部件。
- 预览图中的结构层可点选，点选后同时切换当前路基部件和当前结构层。
- 预览图应表达部件坡度和路缘石高度差；最上方的路基部件只画带部件颜色的顶线，不绘制有厚度的部件块。
- 当前部件没有结构层时，显示 `当前部件未配置结构层`，并允许通过新增结构层进入既有结构层编辑交互。
- 结构层的类型、材料名称、颜色、填充、厚度、内外侧加宽和坡度语义复用既有路面结构层模板；厚度、加宽、坡度的“内外侧是否一致”交互应与单部件模板保持一致。
- 创建命令不接入道路模型、不绘制横断面图、不输出 XML、不触发工程量统计。

## 可复用性说明

- 可复用内容：`FullRoadPavementTemplateModel`、路基部件快照、按部件 key 保留结构层的刷新规则、文件 Bridge 字段、WPF 结构层编辑 helper。
- 临时原型内容：通过临时文件和命令行在 WPF 与 C++ 之间传递点选/确认动作。
- 正式复用前需要改造的内容：模板库管理、与道路模型/横断面图配置的读取入口、统一关系管理提示。

## 与其他模块的依赖关系

- 上游模块：横断面路基模板。
- 下游模块：后续横断面道路模型和横断面图配置可按 handle 读取整幅路模板数据。
- 实体联动行为：当前版本不自动联动，只支持用户手动刷新参考路基模板快照。

## 后续对接正式 EICAD 功能的注意事项

- 后续道路模型生成可按整幅路模板 handle 读取每个部件内嵌结构层。
- 后续应补充模板库、标准断面库、批量应用和引用方重建提示。
