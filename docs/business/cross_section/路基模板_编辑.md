# 路基模板编辑

## 功能范围

本功能用于编辑已创建的 `DnSubgradeTemplateEntity`。用户可通过双击实体触发托管 Ribbon 插件转发，也可由内部句柄命令打开同一个 WPF 参数窗口。

## 命令

- 内部命令：`RD_SECTION_SUBGRADE_TEMPLATE_EDIT_HANDLE`
- 显示名称：按句柄编辑路基模板
- 模块编码：`CROSS_SECTION`
- 业务文档：`docs/business/cross_section/路基模板_编辑.md`

## 流程

1. 托管 Ribbon 插件监听 AutoCAD 双击事件。
2. 若双击对象 DXF 名称为 `DNSUBGRADETEMPLATEENTITY`，插件读取对象句柄。
3. 插件转发命令：`RD_SECTION_SUBGRADE_TEMPLATE_EDIT_HANDLE <handle>`。
4. C++ 按句柄打开实体，读取插入点和模板数据。
5. C++ 通过桥接文件打开 WPF 参数窗口。
6. WPF 参数窗口必须显示实体内上次保存的模板名称、道路等级、显示比例、部件列表、坡度模式、变宽表、坡度变化表和路面结构层模板引用，不得重新初始化为默认模板。
7. 用户确认后，C++ 读取响应文件并回写实体。
8. 用户也可直接拖动实体插入点夹点移动模板图面位置，移动只更新插入点，不改变模板业务参数。

## 可编辑内容

- 模板名称。
- 显示比例。
- 道路等级。
- 左右侧部件列表。
- 部件类型、宽度、坡度、颜色。
- 内侧路缘石和外侧路缘石的启用状态、宽度、高度和埋深。
- 变宽表、坡度变化数据表。
- 路面结构层模板启用状态、模板 handle 和模板名称；任意部件类型均可通过点选 DWG 中的 `DnPavementLayerTemplateEntity` 绑定模板，也可清除绑定。
- CAD 图中部件标注使用中文部件名，并在模型空间竖向绘制以减少横向重叠；WPF 预览图显示部件宽度和坡度。
- 旧高度差输入不再开放。部件高差由路缘石高度派生：内侧路缘石高度影响当前部件内侧起点，外侧路缘石高度影响外侧相邻部件起点。
- 路缘石宽度不改变部件总宽，也不改变相邻部件累计宽度；CAD 实体和 WPF 预览只在当前部件内部叠画路缘石构造。
- 路缘石顶部与当前部件顶部一致并保持平行，按部件颜色填充并加白色描边。
- 坡度按“平坡为 `0`、顺时针为负、逆时针为正”换算图形方向；左侧正坡向外降低，右侧负坡向外降低。
- CAD 图中插入点夹点可拖动，用于调整整个模板实体位置。

## 边界

- WPF 不直接操作 `AcDbEntity`、`AcDbObjectId`、`ads_name`。
- C++ 回写前会做基础参数归一化与校验。
- 当前未实现按路线桩号重算变宽/变坡图形。

## 2026-06-24 更新

- `DnSubgradeTemplateEntity` 的部件中文标注改为竖向绘制；编辑后刷新实体时沿用该显示规则，模板名称和 `CL` 标记不旋转。

## 2026-06-23 更新

- 编辑窗口新增内侧路缘石和外侧路缘石两组参数，可分别设置宽度、高度和埋深。
- `DnSubgradeTemplateEntity` 持久化版本升级，旧图纸读取时新增路缘石字段默认为未启用。
- 编辑已有模板时保留已保存的左右侧默认颜色、坡度和路缘石参数；默认模板重新生成时不再自动带路缘带。
- 编辑窗口删除旧部件高度差输入，路缘石高度开始驱动相邻部件高差。
- 路缘石预览和 CAD 实体显示改为同部件色填充并使用白色描边。

## 2026-05-20 更新

- 路面结构层关联升级为独立模板实体引用，不再使用部件内单一厚度作为结构层表达。
- 编辑窗口的“选择结构层模板”会向 C++ 发送点选动作，由 ObjectARX 校验所选对象必须是 `DnPavementLayerTemplateEntity`，再回填当前部件。
- 绑定结构层模板不限制部件类型；道路模型生成阶段统一读取被绑定模板并生成结构层边界线和弱化填充面。

## 2026-05-19 更新

- `DnSubgradeTemplateEntity` 新增插入点夹点，支持在 CAD 图中拖动移动模板位置。
- 夹点移动仅改变实体插入点和图面显示位置，不改写模板名称、道路等级、部件、变宽表或坡度变化数据表。
## 2026-05-13 更新

- 双击编辑必须发送带换行的 `RD_SECTION_SUBGRADE_TEMPLATE_EDIT_HANDLE <handle>`，确保句柄参数立即被命令读取。
- WPF 编辑模式必须从实体读取已保存的部件、道路等级、数据表和预览状态，不得重新生成默认模板。
- 预览图支持通过部件本体和命中区域直接选中部件；左、右按钮按横断面几何顺序移动。
