# 路基模板创建

## 功能范围

本功能属于横断面设计模块，用于创建独立的路基模板自定义实体。当前版本只要求用户点取插入点，不选择、不绑定既有道路中线；实体自身绘制道路中线标记，并支持部件绑定已创建的路面结构层模板实体。

## 命令

- 用户命令：`RD_SECTION_SUBGRADE_TEMPLATE_CREATE`
- 显示名称：创建路基模板
- 模块编码：`CROSS_SECTION`
- Ribbon 位置：`RoadProto / 横断面设计 / 创建路基模板`
- 自定义实体：`DnSubgradeTemplateEntity`
- DXF 名称：`DNSUBGRADETEMPLATEENTITY`

## 流程

1. 用户运行 `RD_SECTION_SUBGRADE_TEMPLATE_CREATE`。
2. 命令提示用户在图中点取路基模板实体插入位置。
3. C++ 生成默认模板数据，并通过桥接文件打开 WPF 参数窗口。
4. 用户在窗口中编辑模板名称、显示比例、道路等级和部件参数。
5. 用户确认后，WPF 写回响应文件。
6. C++ 读取响应文件，创建 `DnSubgradeTemplateEntity` 并刷新图形。

## 初始参数

高速公路默认部件：

- 左侧中分带 `1.5`
- 左侧行车道 `3.75 * 2`
- 左侧硬路肩 `3`
- 左侧土路肩 `0.75`
- 右侧对称

城市快速路默认部件：

- 左侧中分带 `1`
- 左侧行车道 `3.75 * 2`
- 左侧侧分带 `1`
- 左侧慢车道 `3`
- 左侧人行道 `4`
- 右侧对称

二级、三级、四级道路默认部件：

- 二级道路：左侧行车道 `3.75`、硬路肩 `1.5`、土路肩 `0.75`
- 三级道路：左侧行车道 `3.5`、硬路肩 `0.75`、土路肩 `0.75`
- 四级道路：左侧行车道 `3.0`、硬路肩 `0.25`、土路肩 `0.5`
- 右侧对称

一级道路、城市主干道、城市次干道和城市支路均生成左右对称的非空默认模板。所有道路等级的默认模板初始部件均不再包含路缘带；`路缘带` 部件类型保留，供用户手动新增。默认模板中出现的所有中分带部件，外侧路缘石默认启用，宽度、高度和埋深均为 `0.15`。

## 部件规则

- 左侧部件只在中线左侧绘制，右侧部件只在中线右侧绘制。
- 宽度变化表按“桩号、加宽值”保存；当前未关联路线桩号，实体图形和预览先按基础宽度显示。
- 后续绑定道路中线后，实际宽度按 `基础宽度 + 加宽值` 计算，且向中线外侧加宽。
- 坡度支持固定值和变化值；选择变化值后，固定坡度输入置灰，坡度只能从“坡度变化数据表”获取。
- 当前未关联路线桩号，实体图形和预览在变化坡度模式下先使用坡度变化表首行作为示意坡度；后续绑定道路中线后按桩号查询坡度变化表。
- 部件支持内侧路缘石和外侧路缘石两组参数。每组包含“是否启用”、宽度、高度和埋深；未启用时该组尺寸按 `0` 保存。
- 路缘石宽度不扣减部件总宽。部件普通断面的有效宽度仍为部件总宽；路缘石按内侧或外侧向当前部件内部重复绘制，用于表达构造宽度、高度和埋深。
- 路缘石顶部与当前部件顶部一致并保持平行，图形中按部件颜色填充并加白色描边；埋深继续表达路缘石低于相邻较低部件起点的下埋尺寸。
- 路缘石高度驱动部件高差。内侧路缘石高度作用于当前部件，当前部件内侧起点相对上一内侧部件抬高同等高度；外侧路缘石高度作用于外侧相邻部件，当前部件外侧之后的下一部件起点降低同等高度。
- 旧“高度差”输入从 WPF 参数窗口和 Agent 用户协议中删除；旧文件中的内部字段读取后归一化为 `0`。
- 默认坡度按左右侧写入：左侧行车道、硬路肩、路缘带为 `0.02`，右侧为 `-0.02`；左侧土路肩为 `0.03`，右侧为 `-0.03`；其他部件默认 `0`。图形和道路模型按“平坡为 `0`、顺时针为负、逆时针为正”的符号约定换算外向高程，因此左侧 `0.02` 向外降低，右侧 `-0.02` 向外降低。
- 任意路基部件类型均可启用路面结构层模板关联；用户点击“选择结构层模板”后回到 CAD 图中点选 `DnPavementLayerTemplateEntity`，系统回填模板 handle 和名称。
- “清除结构层模板”会清空当前部件的结构层模板 handle 和名称，使该部件不参与道路模型结构层生成。
- 二维预览图中每个部件应显示部件类型、宽度和坡度，并裁剪在预览区域内，不得遮挡右侧参数 UI。
- CAD 图中的路基模板自定义实体部件标注使用中文部件名，并在模型空间按竖向方向绘制，减少相邻部件标签横向重叠；模板名称和 `CL` 标记保持横向。

## 颜色约定

默认颜色按 AutoCAD ACI 色号生成 RGB 显示色：

| 部件类型 | 左侧 ACI | 右侧 ACI |
| --- | ---: | ---: |
| 中分带 | 42 | 52 |
| 行车道 | 32 | 62 |
| 侧分带 | 92 | 102 |
| 硬路肩 | 22 | 72 |
| 慢车道 | 22 | 72 |
| 土路肩 | 12 | 82 |
| 人行道 | 12 | 82 |
| 路缘带 | 43 | 61 |

## 当前限制

- 本版不选择、不绑定道路中线。
- 变宽表和坡度变化数据表暂不按桩号实时驱动图形。
- 路面结构层模板已作为独立 `DnPavementLayerTemplateEntity` 实现；路基模板部件只保存引用 handle 和名称，不复制结构层详细参数。
- AutoCAD 图形界面中的真实 Ribbon 点击、双击编辑、DWG 保存重开仍需人工验证。

## 2026-06-24 更新

## 2026-06-23 更新

- 路基模板部件新增内侧路缘石和外侧路缘石配置，分别保存启用状态、宽度、高度和埋深。
- 路缘石宽度改为部件内部重复绘制，不扣减部件总宽。
- 默认模板初始部件删除路缘带；路缘带类型仍可手动新增。
- 默认模板中所有中分带外侧路缘石默认启用，宽度、高度和埋深均为 `0.15`。
- 默认颜色改为按左右侧和部件类型匹配 ACI 色号；路缘带左侧为 `43`，右侧为 `61`。
- 默认坡度改为按左右侧生成，并按旋转符号换算图形方向：左侧 `0.02` 向外降低，右侧 `-0.02` 向外降低。
- 路缘石高度替代旧部件高度差输入；内侧路缘石高度移动当前部件，外侧路缘石高度移动外侧相邻部件。
- 路缘石绘制改为同部件颜色填充并增加白色描边，顶部与当前部件顶部一致。

## 2026-05-20 更新

- 路基模板部件的路面结构层关联从旧的单一厚度表达升级为独立模板实体引用。
- 所有部件类型均允许绑定路面结构层模板；是否生成结构层由部件保存的模板 handle 决定。
- 绑定动作通过 WPF `PickPavementLayerTemplate` 响应回到 C++ ObjectARX 点选 DWG 实体完成，WPF 不直接读取 CAD 对象。
