# Agent 泛化规则总表

本文档沉淀 RoadProto 联调中抽象出来的跨工作流泛化规则。这里写“所有可复用工程 Agent 都应遵守什么”，具体 RoadProto 实现细节仍写入 `docs/agent/` 和 `docs/business/agent/`。

每条规则必须包含：

- 适用范围。
- 触发条件。
- 程序语义。
- 不适用边界。
- 落地层级。
- 测试样例。

## G-001 基于蓝本的实体派生创建

### 适用范围

适用于所有支持新建、且具有完整初始参数结构的工程实体。实体可以是模板、模型、配置、样式或其他带默认参数 / 初始参数的可创建对象。换句话说，“工程对象”不是固定写死的少数名词，而是所有可创建、可持久化、且能由一组初始参数完整描述的实体。

RoadProto 当前例子包括：

- 路基模板。
- 边坡模板。
- 路面结构层模板。
- 道路模型。
- 横断面图配置。

### 触发条件

用户表达中同时出现：

- 创建类动作：`创建`、`新建`、`生成`、`做一个`、`建一个`、`复制一个`。
- 可新建工程对象：某类带初始参数结构的实体。
- 蓝本引用：`基于原本的`、`基于默认的`、`在原来的基础上`、`照着刚才那个`、`按现有的`、`复制一个类似的`。
- 参数补丁表达：该实体对外开放参数中的任意可写字段变化。局部修改表达本质上是对新实体开放参数的 patch，任何已纳入 Schema 的参数都可以成为补丁字段。

### 程序语义

系统应识别为：

```text
CreateFromBase + ParameterPatch
```

执行顺序为：

```text
识别主动作 Create
-> 识别工程对象类型
-> 解析蓝本来源
-> 读取或生成蓝本完整参数
-> 将用户表达映射为该实体开放参数的 patch
-> 应用 patch 得到完整新对象参数
-> 调用 Create Tool 创建新实体
```

除非用户明确说“修改原来的对象”或“直接改这个对象”，否则蓝本只作为参数来源，不作为被写入对象。最终 Tool 必须仍是创建类 Tool，不得因为句子中出现“增加、删除、修改、改成”等局部操作词就改派到修改类 Intent。

实现时可以把这条规则理解为：先得到一个完整实体参数对象，再把用户表达出的局部参数变化应用上去，最后把 patch 后的完整参数交给创建 Tool。Adapter 不应接收“最右侧增加一个 10 米行车道”这类自然语言，只接收已经归一化后的结构化参数。

### 不适用边界

- 用户明确说“修改 A”“把原来的 A 改成”，应进入修改类 Intent。
- 用户只说“基于原本的创建一个”，没有参数补丁时，可以按蓝本完整复制创建；若缺少新对象名称、插入位置或蓝本不唯一，应追问。
- 用户提到的参数不属于该实体开放 Schema 时，不允许模型自由发挥；规则层应追问或提示当前暂不支持该参数。
- 蓝本来源不唯一时，不得猜测，应要求用户点选、输入名称或从候选中选择。

### 落地层级

| 层级 | 责任 |
| --- | --- |
| 入口路由 | 保持主动作是 Create，不被局部“增加/修改/删除”操作词抢走 |
| Intent / Schema | 创建 Intent 声明 `baseRef` 和开放参数补丁槽位 |
| 规则层 | 获取完整蓝本参数，并将 patch 应用到完整参数结构 |
| 状态机 | 蓝本不明确时保持追问状态，并保存已确认字段 |
| UI | 支持输入名称、点选对象或候选选择来补齐蓝本 |
| Tool Adapter | 只接收完整创建参数，不解释自然语言 patch |

### 测试样例

```text
创建路基模板，基于原本的路基模板，最右侧增加一个10米的行车道
=> Create: SubgradeTemplate
=> Base: 原本的路基模板 / 默认完整参数
=> Patch: addComponent Right OutsideOf TravelLane width=10
=> Tool: SubgradeTemplate.Create
=> 不修改原路基模板
```

```text
基于刚才那个道路模型，新建一个采样间距改成10米的
=> Create: RoadModel
=> Base: 最近触碰道路模型
=> Patch: samplingInterval=10
=> Tool: RoadModel.Create
=> 不修改原道路模型
```

```text
照着默认边坡模板做一个，把第一级坡率改成1:1.5
=> Create: SlopeTemplate
=> Base: 默认边坡模板
=> Patch: firstSlopeRatio=1:1.5
=> Tool: SlopeTemplate.Create
=> 不修改默认边坡模板
```
